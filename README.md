# StudyFlow — локальный помощник по учебному стрессу

## Запуск

Открой start.cmd и http://localhost:3000. Для другого устройства в одной сети — start-network.cmd и адрес компьютера с портом 3001. После установки зависимостей интернет не нужен. Для первого открытия страницы сервер на компьютере должен работать. Загруженная страница анализирует записи в браузере даже без связи с сервером. Это не установленное PWA: открытие новой вкладки при выключенном сервере не поддерживается.

## Локальный ML

Новые записи обрабатываются прямо в браузере. Веса модели входят в сборку сайта; внешних API и загрузки моделей при анализе нет. Multinomial Naive Bayes обучается на префиксах слов и парах токенов на трёх языках. Пять классов: волнение перед сдачей, откладывание задач, усталость, перегрузка, баланс. При недостатке известных признаков или слабом различии классов вывод помечается как неуверенный.

Обучение воспроизводится командой `npm run ml:train`. Учебный корпус находится в ml/corpus.json; его можно пополнять размеченными примерами. После обучения выполни `npm run build` и перезапусти сервер. `npm run ml:evaluate` запускает небольшую проверку на пяти дополнительных искусственных предложениях. Результат текущей версии 5/5 не является оценкой точности на реальных студентах.

Корпус содержит 80 искусственно составленных примеров на русском, казахском и английском. Это учебный классификатор, не большая языковая модель: он не ведёт свободный диалог, может ошибаться в отрицаниях, сложном контексте и смешанных ситуациях. Вероятность корректности не откалибрована. Нет автоматического обучения на личных дневниках и заявлений о клинической точности.

Балл нагрузки рассчитывается отдельно по правилам из самооценки, сна, нагрузки и ключевых слов; он не обучен на валидированном тесте. Рекомендации выбираются из подготовленной библиотеки. Эмоции — предположения по выбранной теме. При неуверенности предлагается уточнить описание.

## Что работает

Дневник с настроением, сном, активностью и учебной нагрузкой; локальный разбор; история; графики; индивидуальный профиль; экспорт JSON; удаление записей. Первая личная запись заменяет начальные учебные примеры. Старые записи сохраняют исходный тип анализа и не переоцениваются автоматически. Данные находятся в localStorage конкретного браузера и адреса сайта, без синхронизации.

## Стек

Next.js, TypeScript, Tailwind CSS, Recharts, Zustand, Zod. src/lib/local-ml.ts — локальный вывод, ml/train.ts — обучение, src/lib/local-model.json — обученные параметры. Исходный демоалгоритм сохранён для старых примеров и расчёта условного балла. Rust/Axum backend подготовлен для необязательного OpenAI API. Интерфейс теперь всегда использует локальную модель. Отдельный /api/analyze по умолчанию также локален; при RUST_API_URL использует Rust. Авторизация, PostgreSQL и синхронизация ещё не реализованы.

## Проверки

`npm test` — проверки анализа, схем, ID для HTTP и локального ML с заблокированным fetch.
`npm run build` — производственная сборка.
`npm run ml:evaluate` — небольшой синтетический контрольный набор.

## Показ преподавателю

Открой «Записать своё состояние», введи ситуацию и получи «Локальная ML-модель». Покажи историю после обновления страницы, затем график и профиль. Объясни: обучен небольшой классификатор; обработка выполняется в браузере, рекомендации выбираются из библиотеки, база обучения пока синтетическая.

## Новые возможности

- «Моя неделя»: последние 7 календарных дней, средние по заполненным дням, частые темы и следующий шаг. Пропуски не считаются нулями. Несколько записей в день сначала усредняются. Сравнение с предыдущими 7 днями появляется при наличии минимум 3 заполненных дней в каждом периоде. Личные записи не смешиваются с примерами. Отчёт скачивается в TXT на выбранном языке.
- «Настройки» в верхней панели: русский, қазақша, English; светлая или тёмная тема; тон «Мягко», «По делу», «Как тренер». Настройки сохраняются в этом браузере. Тон доступен и в форме записи, меняет только подачу рекомендаций. Сохранённые баллы и факты не пересчитываются.
- Текст пользователя остаётся на языке оригинала. Интерфейс, известные шаблоны результатов и рекомендации переведены; произвольный ответ внешнего ИИ автоматически не переводится.
- Детектор перед сохранением отмечает явные расхождения: учёба весь день при 0 ч, отсутствие занятий при ненулевой учёбе, отсутствие сна при 4+ ч, числовые расхождения сна/учёбы больше часа, отсутствие движения при 30+ мин. Это ограниченный набор правил для RU/KK/EN, не детектор лжи. Можно исправить форму или подтвердить данные; подтверждения сохраняются в записи.
- Корпус расширен до 80 синтетических примеров на RU/KK/EN. Качество на реальных студентах не оценивалось.

Дополнительные проверки: tests/features.test.ts проверяет даты, агрегацию, языки и детектор; tests/interface.test.ts проверяет взаимодействие компонентов и сохранение настроек в DOM-среде. Она не проверяет реальную браузерную вёрстку; предупреждение графика о нулевых размерах в этой среде связано с отсутствием layout.
